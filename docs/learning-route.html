先备知识

  • 科研基本素养：分清自己的实际结果、论文结论和待验证推断；每个科学主张能够找到来源、参数和适用范围。
  • 理论与量纲：理解研究物理量的定义、单位、近似与参考态，知道哪些现象模型能表达，哪些不能。
  • 可复现记录：保存结构来源、许可证/数据许可、软件版本、输入、停止条件、种子与分析过程；异常结果不隐藏。
  • 统计与对照：识别采样相关性、数值/模型/统计误差，以及目标性质需要的独立验证。
  • 科研诚信与安全：不把未执行的计算写成完成，不把自动定位信号当完整参数，不公开订阅全文、凭据或未授权计算资源。

数值精度 / 方法准确性
参数收敛控制数值精度；与参考理论或实验的差异属于准确性与模型局限。参数更大或训练 loss 更低不自动消除模型误差。
采样与不确定性
轨迹帧通常相关；需要说明平衡/生产段、独立重复、拟合区间与误差估计，不能把帧数当独立样本数。
可追溯 / 可复现
保存来源、版本、输入与处理过程，使别人能检查和重算；受版权或许可证限制的资源应提供取得方式而非违规公开。

练习与交付

模拟步骤

  1. 使用 DFT 前查：泛函/赝势与版本、k 点/截断能、电子/离子收敛、磁性/U/色散和参考态是否与问题一致。
  2. 使用 NEB 前查：端点、路径、图像和受力收敛；报告的是静态势垒还是有限温度自由能，不能混称。
  3. 使用 MD 前查：势的适用域、系综/积分器、时间步、守恒/漂移、平衡段、超胞、生产时长与独立重复。
  4. 解释输运前查：坐标展开、MSD 时间窗、跳跃统计、自扩散与集体电导定义，以及温度/相变与外推假设。
  5. 使用 AI/MLIP 前查：数据理论层次、重复/相邻帧泄漏、独立评估、域外与物理性质验证；伪标签不能冒充 DFT 真值。
  6. 写论文或汇报前查：结果是否真实完成、图表/单位是否可复算、替代解释与局限是否清楚、参考与数据许可是否齐全。

入门 · 从教程走到一个可复现算例

先从综述、软件/协议论文建立地图，再选一条任务线完成闭环：结构 → 方法 → 分析 → 文献对照。计算论文无需一上来就包含 DFT、MD、AI 和电芯实验的全部工具。

先备知识

  • 通过 Baseline 的输入、收敛、单位与可复现记录检查。
  • 会读摘要、方法、主图和补充信息；从原文找关键参数，区分软件默认值与作者设置。
  • Python 能读取结构或轨迹，计算统计量并画图；认识 ASE/pymatgen、VASP/VASPKIT、LAMMPS 或 Materials Studio 各自角色。
  • 先选一个任务与一种材料，不同时学习所有软件；MS 标签只表示已整理元数据里的 Materials Studio 使用依据。
结构优化 / 静态计算
先获得合理结构，再对固定结构计算性质。结构优化、DOS 和扩散并不是同一种任务。
DOS 与能带
描述电子态分布与色散。它们可以帮助解释电子性质，但不能单靠能带证明离子导电更好。
MD / AIMD / MLIP-MD
经典 MD 使用经验势；AIMD 逐步计算电子结构力；MLIP 用训练好的能量/力模型驱动 MD。轨迹分析仍需独立验证。
RDF / 配位数
RDF 描述径向结构统计，配位数依赖积分截断与原子对定义。结构峰不是直接的反应证据。
MSD / 扩散系数
展开周期坐标后，在线性扩散时间区间从 MSD 斜率估计 D；3D 各向同性时 D=斜率/6。弹道段、平台段和跳跃不足时不能硬拟合。
复现 / 外推
复现原文模型与条件是第一步；更换成分、温度或软件会引入新问题，不能沿用原文结论。

练习与交付

模拟步骤

  1. 先读 Urban 等电池计算综述或 Butler 等材料机器学习综述，再读 ASE/pymatgen 与 VASPKIT 协议论文；写一页方法选择表。
  2. 任务线 A：选一个简单非磁性晶体做优化和静态性质；完成结构、能量与数值收敛对照，不把软件输出当成机制。
  3. 任务线 B：用可核对的公开 MD 轨迹或可靠示例力场分析 RDF、配位数、MSD 与 D。说明平衡段、生产段、坐标展开及拟合窗口。
  4. 从复现论文的方法与补充信息提取参数表：体系、原子数、模型、时间尺度、软件版本、温度/压力、对照与输出量；缺项标记未知。
  5. 用同一脚本生成重复轨迹结果及误差，不同条件的曲线放在同一坐标轴；先复现趋势再尝试一个小改动。
  6. 形成输入/分析/图表/讨论四部分小报告，注明与原文不一致的资源或模型条件。

实验验证分类

  • 结构与动力学数值对照计算路线必做

    DFT 对照晶格/能量/力；MD 对照 RDF、密度、扩散统计或参考轨迹。按选定任务做，不要求所有指标。

  • XRD、Raman 或 FTIR合作/已有数据可选

    结构与局部环境对照。实验平均结构与模拟单一构型不能一一等同。

  • EIS 与温度依赖电导研究离子输运时相关

    需要几何尺寸、接触、拟合模型与离子/电子贡献说明；缺少这些时不直接用一个电阻数与 D 对比。

  • CV、恒流充放电电极电位/容量主张时相关

    真实电池测试受电解液、负载、倍率和副反应影响；基础电子结构练习不强制做整套测试。

intermediate

进阶 · 机制、统计与可靠的 DFT→MD→AI 链条

开始把能量、路径、统计与机制连起来。经典电压/扩散论文和成熟 MLIP 方法放在这里；使用机器学习不是创新本身，要证明其在具体体系里可信且有用。

先备知识

  • 能够复现基础计算，熟悉晶体缺陷、自由能/化学势、势能面和统计采样。
  • 按方向补 DFT+U/磁序/色散、NEB、AIMD 或经典力场参数化；不要混用不相容的参考能。
  • 会做误差传播、独立重复、时间序列相关分析；理解采样不足、有限尺寸与高温外推。
  • AI 路线须掌握训练/验证/测试区别、构型分组、域外检测和物理验证。用于问答的 QLoRA 与用于原子力的 MLIP 是两类模型。
形成能 / 凸包 / 化学势
比较相稳定性需要一致参考态、组成和计算层次。离凸包距离不直接证明可合成，也不包含所有温度/动力学效应。
平均嵌入电压
近似由不同嵌锂状态与 Li 金属参考能的反应能差决定；温度/熵、U 和参考态会改变结果。能量或带隙不是电池电压。
迁移 / 缺陷 / 协同扩散
单离子最小路径、空位浓度和多离子协同运动可能同时影响输运；一个 NEB 势垒不能代表所有机制。
Nernst–Einstein 近似
用自扩散系数估计电导率时忽略离子运动的交叉相关；需明确近似并与集体电导/实验区分。
MLIP 训练域
模型只在足够覆盖的成分、结构、温压、电荷和反应环境中才可能可信；力 RMSE 低不保证正确势垒或长时 MD。
数据泄漏
相邻轨迹帧随机分到训练与测试会过于乐观。按轨迹/结构族/相或材料划分，并检查预训练模型可能见过的来源。

练习与交付

模拟步骤

  1. 选题线 A：重现一个已建立电极的电压/相稳定性趋势；对磁序、U、结构与参考态做有目的的敏感性检查。
  2. 选题线 B：在固态电解质或缺陷材料中定义迁移端点，做多路径 NEB，并比较端点/图像/受力收敛；必要时用 AIMD 判断机制。
  3. 对输运轨迹开展超胞、时长、独立初始化、拟合时间窗与温度检查；给出 D(T) 的区间，不在无跳跃条件下报告假精度。
  4. 拟合 Arrhenius 前检查同一相和同一机制是否成立；若相变或机制改变，不用一条直线强行外推室温。
  5. AI 线先用冻结的通用势做测试而非立刻训练：对独立 DFT 构型测能量/力，另验证结构、势垒和动态稳定性。
  6. 需要微调时仅生成有明确覆盖目标的 DFT 标签；按独立来源分组，记录增量标签预算，并与未微调模型和简单基线比较。

实验验证分类

  • 收敛、有限尺寸、采样与模型对照计算主张必做

    DFT/NEB/AIMD/MLIP 各有不同验证项目；按目标误差预算选择，不存在统一的固定测试步数。

  • EIS、PFG-NMR 或温度依赖电导输运主张的合作对照

    PFG-NMR 多对应自扩散，EIS 测到的电导包含样品与界面影响；与模拟比较时匹配相、成分、温度与尺度。

  • XRD / operando XRD / XAS电极结构与氧化还原对照

    用于相变、局域配位或价态相关证据。DFT 电荷分区不是直接实验氧化态。

  • XPS / Raman / FTIR / 界面形貌反应与界面主张的合作对照

    谱图需化学指认与表面/体相差异；终点产物支持并不唯一证明模拟中的反应路径。

下面按八条方向展开。每篇有唯一主阶段；同一论文也可作为多个方向的支撑，因此方向篇数不能相加当作库总量。前沿标签指本库的选题地图，不保证新颖性、可发表性或工业可用性。

  • 选题前再次检索近期文献、数据/代码与团队资源；本页不是截至当天的穷尽性前沿调查。
  • 预算 DFT 标签、长轨迹与实验合作成本；电脑可先做小模型分析，大规模任务需要组内计算资源。

研究机会 / 新颖性
论文暴露的限制可生成研究假设，但“别人没做过”须靠额外检索证实；负结果和复现偏差也有科学价值。
域外 / OOD
超出训练成分、结构或状态分布。模型自信不代表正确，需要域外识别和独立标注。
主动学习
用当前模型识别值得标注的构型或材料，再计算/测量更新；选择规则必须被独立验证。
通用原子势 / 微调 / 蒸馏
预训练势可作为起点，微调适配目标，蒸馏加快推断；不能把“少量标签有效”的个例变成所有体系的保证。
计算—实验闭环
模型提出候选，真实计算/测量验证，再将结果回流。只有问答或检索的 agent 并不等于完成了闭环。

FRONTIER

固态电解质：缺陷、无序与集体离子输运

从 LGPS 等经典 AIMD 到 MLIP 长时/大超胞输运，研究通道、缺陷与无序如何共同影响可观测的电导。

开放问题：改变缺陷或无序后，提高的是单离子自扩散、离子数，还是集体电荷输运？结论对超胞与温度是否稳健？

进入条件

  • NEB、MSD、独立采样与 Nernst–Einstein 近似。
  • 固态电解质的结构、占位、缺陷与相稳定性。
协同扩散
多个离子的关联跳跃或集体运动，不一定能被一条单离子路径充分描述。
有限尺寸效应
周期边界与超胞尺寸会改变通道连通、结构涨落和扩散事件；必须检查目标性质。

练习与交付

模拟步骤

  1. 复现 LGPS/相关体系的结构与一条已报道路径；作为物理基线。
  2. 用独立 DFT/AIMD 对 MLIP 的势垒、力与结构先验验收。
  3. 比较不同尺寸、温度、缺陷/无序配置；检查框架是否保持目标相。
  4. 分析 MSD、跳跃网络和交叉相关；给出自扩散与电导估计的定义及误差。

限制 / 不外推

  • 静态低势垒不保证低温快速导电。
  • 短 AIMD 无跳跃不能证明完全不导电；高温熔化轨迹不能代表原固态相。
  • 不把通用势在三个示例体系的表现外推到所有电解质。

通关清单

  • 一个同时包含数值/统计验证与迁移机制的小复现。
  • 清楚解释自扩散系数与离子电导率是否等价。

可审计计算工作流与 AI 闭环

从结构搜索、高通量与数据平台到自动候选/验证闭环；把真实工具执行、失败处理、来源和权限检查纳入系统。

开放问题：自动系统能否在固定预算和独立评价下减少无效计算、提高候选质量，而不是只生成更流畅的文字？

进入条件

  • 可复现任务、工作流/队列、结构去重与方法验证。
  • RAG 引用核验、工具权限、失败处理与人在环确认。
Agent 工具执行
根据任务选择受限工具、读取结果再决策；静态关键词回答或知识图谱本身不等于自主完成研究。
人在环
对许可、危险实验、集群任务、模型异常与高影响决策由人审核；不是每一步都无限自动执行。
Provenance / 溯源
记录输入、来源、版本、参数、计算状态和输出关系；未执行的计算不能标为成功。

练习与交付

模拟步骤

  1. 先复现一个公开高通量或界面搜索流程，检查结构、参数与输出质量。
  2. 建立任务状态机：待验证 → 执行 → 质量检查 → 可用/失败；限定工具和预算。
  3. 比较人工/规则流程与 AI 选择的候选：独立成功率、质量、成本、无效重试与引用正确性。
  4. 对写入、作业提交、机构访问与实验建立人类确认；不把订阅全文或私人映射上传仓库。

限制 / 不外推

  • 高通量工作流、闭环筛选与聊天 Agent 是相关但不同的能力。
  • 自动化不能扩大数据库下载/许可证或实验安全授权。
  • 只有精美页面与高回答流畅度不能证明研究效率或材料发现能力。

通关清单

  • 一个小而真实的可回放工作流，不先追求全自动实验室。
  • 所有结果有状态和来源；工具失败时系统不编造成功。
