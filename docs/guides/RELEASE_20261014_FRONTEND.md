# 简洁前端与中英文论文标题

更新日期：2026-10-14。

## 本版变化

- 首页、基础地图、未来方向、AI 应用与学习路线采用统一的浅色、低装饰布局。首页将服务状态收进可展开区域，问答、论文库、上传与教程仍保留。
- 176 篇目录论文提供小号中文参考译名，显示于列表、数据卡、检索结果和学习路线引用下；英文原题与 DOI 保持不变。支持中文题名检索，引用仍以英文原题为准。
- 个人待补充论文清单只保留为本机 Markdown，不在公开网页或公开指南中展示，也不计入 176 篇目录。
- 五个页面显示同一份公开统计：176 篇论文、998 条问答数据（793 训练 / 78 验证 / 127 测试）。项目更新日期与代表性文献选读截止日期分别标注，不把网站更新冒充一次新的文献检索。
- 未来方向页可展开跳转到当前论文路线的 8 个前沿专题。分类、机会与验证路径属于研究设计建议，不代表本站已完成物理复现。

## 容错与发布保护

中文译名是独立显示数据：缺失、迟到或标题不匹配时，论文库仍加载英文原题；晚到的译名会补到页面，不阻塞检索。静态预览或后端不可用时保留公开标签与搜索配置，不冒称本地服务已连接。

构建验证译名对目录的精确覆盖、英文原题和 DOI 一致性；在写输出前检查所有公开源与生成页面。公开统计仅为聚合值，不公开私人附件键、逐篇下载记录、正文/片段、账号或模型文件。

本版未新增目录论文、未下载待补充清单、未改 Zotero、未重新训练模型。历史版本说明是历史快照；普通新提交不能抹除旧 Git 历史中的风险。
