# AI 在电池材料模拟中怎样落地

更新：2026-10-08。以下研究路线是本站建议，不是已经完成的复现，也不保证可发表。

## 1. 先分清两类模型

| 路线 | 训练输入/标签 | 用途 | 必须验证 |
|---|---|---|---|
| QLoRA 语言模型 | 问题、证据包、引用与拒答答案 | 文献问答、输入日志解释、工具调用建议 | 来源、事实、引用是否支持结论、拒答、独立问题回归 |
| MLIP 原子势 | 构型、DFT 能量/力/应力 | 优化、NEB、MD、结构和输运统计 | 目标域 E/F/应力误差、势垒、轨迹稳定性、扩散和外推 |

给 Qwen 增加论文问答，不会得到能驱动 MD 的力场。MLIP 的训练标签也不能混用不一致的泛函、赝势、自旋或电荷设置。

## 2. 六类场景与技术实现

| 场景 | 数据 → 模型 → 输出 | 最小验证闭环 |
|---|---|---|
| 固态电解质输运 | 结构 + 一致 DFT 标签 → MLIP → MLMD、MSD、温度依赖 | 独立 AIMD/DFT 构型与势垒；多温度、超胞与独立轨迹；相关输运定义 |
| 液态/聚合物电解质 | 配方/MD 溶剂化构型 → 特征模型或 GNN → 排序/代理性质 | 配方或时间留出、条件匹配的实验/DFT 对照、浓度与含水量 |
| SEI 反应 | 界面/扰动/短 AIMD → 主动学习 → 新标签、反应事件 | 留出反应片段；成断键、组分、结构与能量复核；电荷/电势边界 |
| 正极与材料筛选 | 晶体图/组成 → GNN 或基线 → 候选与多目标排序 | 时间/结构族去重留出、DFT 复核；成本和合成可行性，不只形成能 |
| 界面与跨尺度 | 界面候选、局部势垒和输运 → MLIP/连续模型/PINN → 通量/应力等 | 尺寸时间收敛、边界条件、守恒、实验量级；PINN 不补齐缺失物理 |
| 科研证据 Agent | 问题 → 检索 → 有来源的方案/命令草稿 → 复核 | DOI、证据页码、越界拒答、日志、独立问答评估；执行高成本任务前确认 |

方法与实例入口：

- 固态：DPA-SSE 是面向硫化物的预训练深度势，不是“DP-ASE”。[论文](https://doi.org/10.1038/s41524-025-01764-6)
- 主动学习：HAML 连接 AIMD 标注、势训练和 MD 采样。[论文](https://doi.org/10.1038/s41524-025-01747-7)
- 界面：InterOptimus 提供生成候选、MLIP 松弛与 DFT 精修路线；常电势枝晶建模须关注电荷处理。[InterOptimus](https://doi.org/10.1016/j.jechem.2025.03.007)、[DP-QEq](https://doi.org/10.1038/s41467-025-62824-5)
- 正极：可参考 CHGNet 在高镍正极结构演化问题中的应用，不能把通用力误差直接等同于电压或相变准确。[论文](https://doi.org/10.1016/j.mtener.2025.101841)
- 聚合物自动化：PEMD 是模拟流程工具，与本项目文献 Agent 不同。[论文](https://doi.org/10.1039/D5DD00454C)

## 3. 近期进展：读什么、复现什么

这里是截至上述日期的代表性进展，不声称穷尽所有最新论文。

| 论文 | 进展要点 | 建议可复现切口与边界 |
|---|---|---|
| Phuthi 等，Chemistry of Materials，2026，Perspective | 梳理固态电池中 MLIP 的用途、取舍和待解决问题 | 先据其图表整理目标物理量、长度时间尺度、验证方式；展望不是已解决问题。[DOI](https://doi.org/10.1021/acs.chemmater.6c01051) |
| Zhang 等，npj Computational Materials，2026-03-17 | 预训练 MACE 采样、少量 DFT 适配，再蒸馏到 NEP | 从单一固态电解质的独立结构/势垒与 MD 对照开始；论文少数据结果不是任意体系的样本量保证。[DOI](https://doi.org/10.1038/s41524-026-02023-y) |
| Sagireddy 等，EES Batteries，2026-03-11 | MD 采样的溶剂化结构接入结构感知模型，预测 HOMO/LUMO | 先复现采样与数据过滤，核对 DFT 标签和域外配方；轨道能代理不等于已测得的电化学稳定窗口。[DOI](https://doi.org/10.1039/d6eb00024j) |
| Jain 等，Materials Horizons，2026 卷年，首次在线 2025-11-15，Review | 固态电解质设计的机器学习流程综述 | 用其数据、模型和验证讨论做课题检查表；综述建议不作为本项目已有结果。[DOI](https://doi.org/10.1039/d5mh01525a) |

可发表的潜在问题是：预训练势在哪类缺陷/界面失效？少量新增标签是否修复了目标性质？更大的体系或更长轨迹揭示了什么机制？这些都需要基线、消融、误差和物理复核；换一个模型或计算几张图本身不构成创新。

## 4. RTX 3060 6GB：先做小实验

使用隔离环境安装 ASE/MACE，并按[官方接口](https://mace-docs.readthedocs.io/en/latest/guide/ase.html)核对兼容版本。仓库只验证过示例的语法、帮助命令与合成轨迹单测，没有在本机完成模型下载或 MACE 物理计算。

准备合法 CIF，例如从 Materials Project 获取并保存材料 ID、下载日期与原始文件。不要在未检查无序占位、电荷/自旋和模型元素域时直接计算。

```bash
# 在项目根目录；依赖按官方文档安装。第一次调用可能下载模型。
python examples/ai_battery/relax_mace.py input.cif --output-dir out --device cpu --model small

# 确认 CUDA/PyTorch 环境后，可把 --device 改为 cuda；显存以实际小体系测试为准。
python examples/ai_battery/msd_from_csv.py examples/ai_battery/example_trajectory.csv --output out/msd.json --fit-start-ps 0 --fit-end-ps 3
```

优化脚本保存输入哈希、软件版本、模型信息、优化日志与结构。只优化原子位置，不优化晶胞；未收敛会返回非零退出码，不能把保存了结构当成收敛。

MSD 示例输入必须是固定晶胞、均匀时间间隔、固定原子集合、已经正确 unwrap 的坐标。合成 CSV 是弹道式测试夹具，不是扩散轨迹。输出的是三维自扩散候选值：Å²/ps 乘 10⁻⁴ 后为 cm²/s，三维再除以 6。高 R² 不证明进入扩散区间；须检查滞后时间窗、平衡、框架运动、多条独立轨迹和误差。

不要默认扣除 Li 原子平均运动来“去漂移”：它不等于全体系质量加权质心运动，可能改变待测输运。单粒子 MSD 与 collective/correlated conductivity 不同，不能据一个 D 值直接宣称真实电导率。

## 5. 形成研究结果需要留下什么

1. 确定一个体系与物理问题，先选可检验的基线而不是最复杂模型。
2. 保存 DFT 设置、原始结构/轨迹、标签来源、软件与 checkpoint 版本。
3. 分开训练、开发验证与目标域测试；相邻轨迹帧不能随机切分后当作独立泛化。
4. 检查 E/F/应力，再检查势垒、RDF/配位、MSD/温度趋势与机制；依据任务选择模块，不机械凑图。
5. 做超胞、采样时间、拟合区间和随机种子敏感性，报告失败和不确定性。
6. 用条件可比的 DFT/AIMD/实验复核；没有实验时明确计算论文的适用域与限度。
7. 保存运行命令与结果归档。算力、VASP 许可和新实验须在课题组资源范围内。

## 6. 接入真正的 Agent

本项目已有检索、证据注入、引用/数值边界检查和本地模型接口；并不等于无人监管科研系统。下一步按以下顺序做：

问题分类 → 带 DOI/页码的检索 → 证据足够性检查 → 结构化回答或拒答 → 人工审核的计算工具草稿 → 保存执行日志 → 独立回归评估。

QLoRA 接入命令与 RTX 3060 训练见 [模型集成指南](../FINETUNE_INTEGRATION.md)。新数据生成不等于模型训练；引用 ID 存在不等于该引用支持结论。
