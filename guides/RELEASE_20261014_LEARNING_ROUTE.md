# 论文路线与公开发布保护更新

日期：2026-10-14。

## 本版内容

- 新增可展开学习路线页，176 篇论文恰好各有一个主阶段：15 baseline、34 入门、55 进阶、72 前沿。
- baseline 定义为科研中可反复查验的常备参考与基本素养，不当作课程难度或模型对照。五个常备专题交叉参照 48 篇现有论文。
- 八个前沿分支包含问题、模拟路线、验证、论文结构、局限与具体 DOI 引用；这些研究机会不保证新颖性或发表。
- 增加现有目录之外的 11 篇经典方法/规范下载候选，由用户自行按合法权限下载，未宣称取得全文或导入。
- 原有软件标签保留，论文列表增加路线/方向标签；路线支持搜索、阶段筛选、展开/折叠和定位论文条目。

## 验证和边界

本地全套 Python 验证 116 项通过；5 组网页功能测试通过。目录覆盖、交叉引用、链接与转义、页面过滤/展开/定位、公开载荷及本机接口边界均已检查。浏览器实测了候选 DOI 检索、baseline 五组展开与论文返回证据库；候选命中不会被误报为无结果。

本版不重新训练模型，也不把新的教学文本自动混入留出评估。公开训练数据只清除证据包中的私人全文核验痕迹：793/78/127 条数、逐条 ID、来源分组和助手回答保持不变，三路镜像与清单哈希已同步更新。该测试数量是本地完整工作区验证，包含独立保留的已有改动，不表示本版新增了同等数量测试。

公开构建先检查待发布输入，再写输出；公开 Zotero 载荷必须为空，方法证据与正文状态不进入公开包。逐篇本机全文核验标记、机构会话记录已从公开书目移除，科学书目和 WOS 记录标识保留。推送前另检查完整暂存快照，而非只扫描新增文件。私人审计记录、正文/片段、账号路径、凭据与模型权重保持本机隔离；准确本机记录保留在私人文件中。

旧 Git 历史的风险与当前快照分开处理。普通新提交不能清除旧历史中的文件，历史重写/强制推送需要另行确认。本版不宣称历史从未暴露私人元数据。
